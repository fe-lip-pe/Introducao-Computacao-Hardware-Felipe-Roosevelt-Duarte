# 🌐 Princípios de Redes de Computadores e Internet


## 📖 Sobre o Projeto

Este repositório apresenta os conceitos fundamentais das **Redes de Computadores e da Internet**, abordando como dispositivos se conectam, compartilham informações e se comunicam através de protocolos e equipamentos de rede.

---

# 🖥️ O que é uma Rede de Computadores?

Uma rede de computadores é um conjunto de dispositivos interligados que compartilham informações, recursos e serviços.

### Exemplos de dispositivos

- 💻 Computadores
- 📱 Smartphones
- 🖨️ Impressoras
- 🖥️ Servidores
- 📷 Câmeras IP

---

# 🎯 Objetivos de uma Rede

- Compartilhar arquivos
- Compartilhar impressoras
- Compartilhar conexão com a Internet
- Facilitar a comunicação
- Permitir acesso remoto

---

# 🌍 Tipos de Redes

## 🏠 LAN (Local Area Network)

Rede utilizada em pequenas áreas, como casas, escolas e empresas.

**Características:**

- Alta velocidade
- Curta distância
- Baixo custo

---

## 🏢 MAN (Metropolitan Area Network)

Conecta redes dentro de uma cidade.

Exemplo:

- Universidades
- Órgãos públicos

---

## 🌎 WAN (Wide Area Network)

Rede que conecta computadores em grandes distâncias.

O maior exemplo é a **Internet**.

---

# 🌐 O que é a Internet?

A Internet é uma rede mundial formada por milhões de computadores conectados entre si.

Ela permite o compartilhamento de informações através de protocolos de comunicação.

---

# 📡 Equipamentos de Rede

## 🛜 Roteador (Router)

Conecta diferentes redes e encaminha os dados entre elas.

---

## 🔀 Switch

Conecta dispositivos dentro de uma mesma rede local.

---

## 📶 Access Point (Ponto de Acesso)

Permite a conexão de dispositivos por meio de Wi-Fi.

---

## 🌍 Modem

Converte o sinal do provedor de Internet para que o roteador possa distribuí-lo.

---

# 📨 Protocolos de Rede

Protocolos são regras que permitem a comunicação entre dispositivos.

## TCP

- Garante a entrega correta dos dados.
- Utilizado em aplicações que exigem confiabilidade.

## IP

- Responsável pelo endereçamento dos dispositivos.

## HTTP

- Utilizado para acessar páginas da web.

## HTTPS

- Versão segura do HTTP, utilizando criptografia.

## FTP

- Utilizado para transferência de arquivos.

## DNS

- Traduz nomes de sites em endereços IP.

---

# 📍 Endereço IP

Cada dispositivo conectado à rede possui um endereço IP único.

### Exemplo IPv4

```text
192.168.1.10
```

### Exemplo IPv6

```text
2001:0db8:85a3::8a2e:0370:7334
```

# 📊 Modelo Cliente-Servidor

```text
Cliente
    │
    ▼
Servidor
    │
    ▼
Resposta
```

Exemplos:

- Navegador ↔ Site
- Aplicativo ↔ Banco de Dados

---

# 📈 Modelo OSI

O Modelo OSI organiza a comunicação em sete camadas.

| Camada | Função |
|---------|--------|
| Aplicação | Interface com o usuário |
| Apresentação | Formatação dos dados |
| Sessão | Gerencia conexões |
| Transporte | Entrega confiável dos dados |
| Rede | Endereçamento e roteamento |
| Enlace | Comunicação entre dispositivos |
| Física | Transmissão dos sinais |

---

# 🔒 Segurança em Redes

Boas práticas:

- Utilizar senhas fortes
- Atualizar sistemas
- Utilizar firewall
- Utilizar antivírus
- Utilizar conexões HTTPS
- Fazer backups regularmente

---

# 🚀 Vantagens das Redes

- Compartilhamento de recursos
- Comunicação rápida
- Acesso remoto
- Trabalho colaborativo
- Economia de custos

---

# 📚 Conclusão

As redes de computadores são essenciais para a comunicação e o compartilhamento de informações. A Internet, baseada em protocolos e equipamentos de rede, conecta bilhões de dispositivos em todo o mundo e possibilita o funcionamento de diversos serviços digitais utilizados diariamente.
