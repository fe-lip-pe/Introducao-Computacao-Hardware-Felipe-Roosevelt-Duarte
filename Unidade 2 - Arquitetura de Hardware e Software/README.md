# 🖥️ Arquitetura de Hardware e Software

## 📖 Sobre o Projeto

Este repositório apresenta uma introdução à arquitetura de hardware e software, explicando como os componentes físicos e os programas trabalham em conjunto para possibilitar o funcionamento de um computador.

---

# 🧩 O que é Hardware?

Hardware é a parte **física** do computador, ou seja, todos os componentes que podem ser tocados.

## Principais Componentes

### 🧠 Processador (CPU)

É considerado o "cérebro" do computador, responsável por executar instruções e realizar cálculos.

---

### 💾 Memória RAM

Armazena temporariamente os dados dos programas que estão em execução.

Características:

- Memória volátil;
- Alta velocidade;
- Auxilia no desempenho do sistema.

---

### 💽 Armazenamento (HD e SSD)

Responsável por guardar permanentemente os arquivos do computador.

| HD | SSD |
|----|-----|
| Mais barato | Mais rápido |
| Possui partes mecânicas | Não possui partes móveis |
| Menor desempenho | Maior desempenho |

---

### 🎮 Placa de Vídeo (GPU)

Processa imagens, vídeos e gráficos utilizados em jogos, edição e inteligência artificial.

---

### 🖥️ Placa-Mãe

É o componente responsável por conectar todos os dispositivos do computador.

Funções:

- Comunicação entre CPU e memória;
- Conexão de periféricos;
- Distribuição de energia.

---

# 💻 O que é Software?

Software é a parte **lógica** do computador, composta pelos programas responsáveis pelo funcionamento da máquina.

---

## Tipos de Software

### ⚙️ Software de Sistema

Controla o funcionamento do computador.

Exemplos:

- Windows
- Linux
- macOS

---

### 📱 Software Aplicativo

São programas utilizados pelo usuário.

Exemplos:

- Google Chrome
- Microsoft Word
- Visual Studio Code
- Spotify

---

### 👨‍💻 Software de Programação

Ferramentas utilizadas para desenvolver outros programas.

Exemplos:

- Visual Studio Code
- Eclipse
- IntelliJ IDEA
- GCC

---

# 🔄 Relação entre Hardware e Software

O hardware e o software dependem um do outro.

```text
Usuário
   │
   ▼
Software (Sistema Operacional)
   │
   ▼
Drivers
   │
   ▼
Hardware
```

O software envia instruções para o hardware, que executa as operações necessárias.

---

# 🏗️ Arquitetura de Von Neumann

A maioria dos computadores atuais utiliza a arquitetura proposta por John Von Neumann.

Ela é composta por:

- CPU
- Unidade de Controle
- Unidade Lógica e Aritmética (ULA)
- Memória
- Dispositivos de Entrada
- Dispositivos de Saída

```text
          Entrada
             │
             ▼
      ┌─────────────┐
      │     CPU     │
      │ UC + ULA    │
      └──────┬──────┘
             │
      ┌──────▼──────┐
      │   Memória   │
      └──────┬──────┘
             │
             ▼
           Saída
```

# 📊 Comparação

| Hardware | Software |
|-----------|----------|
| Parte física | Parte lógica |
| Pode ser tocado | Não pode ser tocado |
| CPU, RAM, SSD | Windows, Linux, Chrome |
| Sofre desgaste físico | Pode ser atualizado |

---

# 🚀 Importância da Arquitetura

Uma boa arquitetura proporciona:

- ⚡ Maior desempenho
- 🔒 Mais segurança
- 💾 Melhor gerenciamento da memória
- 🚀 Execução mais rápida dos programas
- 🔧 Facilidade para manutenção

---

# 📚 Conclusão

Hardware e software trabalham em conjunto para garantir o funcionamento dos computadores. Enquanto o hardware fornece os recursos físicos, o software controla esses recursos e permite que o usuário execute tarefas. Compreender essa arquitetura é essencial para estudantes e profissionais da área de tecnologia.
